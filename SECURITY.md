# Privacy and security

InkRelay is a local desktop companion, not an authenticated network service. Keep its default loopback address. LAN/internet exposure requires a separate authentication, authorization and browser-origin security design.

Never attach personal handwriting, canonical event logs, Obsidian vaults, notebook-assignment metadata, pen identifiers, environment files, API keys or unredacted screenshots to a public report. Reproduce issues with artificial strokes and fake identifiers. A Git ignore rule does not erase history or protect files that were already tracked.

For a suspected vulnerability, use the repository host's private vulnerability reporting facility if the maintainer has enabled one. If no private contact method exists, first ask for one in a minimal issue without exploit details or personal data. This repository does not publish a private personal contact address.

Source publication uses an allowlisted history-free snapshot generated by `scripts/prepare-publication.mjs`. Review its manifest before uploading. Patterns can catch common mistakes; they cannot prove that arbitrary prose contains no private information. See `docs/publication.md` for the owner review process.
