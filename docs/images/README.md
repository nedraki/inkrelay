# README image provenance

The seven numbered JPEG demo images are actual browser captures of InkRelay running locally with a separate synthetic dataset. The notebook names “Small ideas” and “Weekend sketches”, single-line lettering, sketches, pen identity and page identities were invented for documentation. No personal corpus, device connection, private environment file, user vault or model response was loaded. The example vault is a separate temporary folder. Images of individual controls are cropped browser captures; UI content was not redrawn or replaced.

## Replacing or adding an image

Keep personal screenshots ignored by default. Capture from a fresh, isolated demo, or use only specific screenshots the owner has explicitly selected for public documentation. An offer to share notes is not blanket permission to browse or publish other notes. Check visible writing, notebook names, device identifiers, paths and background content, and check embedded metadata before approval. Keep the original personal files out of the source.

The publication policy pins each approved image's exact SHA-256. A changed image fails export until it is visually reviewed and its hash updated deliberately. `.gitignore` has exceptions for these ten exact filenames only; other screenshots remain private. Do not add wildcard image exceptions or skip the text/privacy scan for other files. Capture provenance changes belong in this document. Refresh the history-free source snapshot and owner review checklist after changes.
